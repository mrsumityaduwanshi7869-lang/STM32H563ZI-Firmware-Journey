# Day 02 – LED Blink

## Objective
Implement LED blinking using GPIO register programming and understand software-based timing.

## Hardware
- NUCLEO-H563ZI
- STM32H563ZIT6
- USB cable
- Onboard LD1 green user LED

## Concepts Learned
- GPIO output
- GPIOB MODER
- GPIOB ODR
- Software delay
- Infinite loop
- Bit manipulation

## Working Principle
LED ON → Delay → LED OFF → Delay → Repeat

## Result
Successfully implemented LED blinking on the NUCLEO-H563ZI.

## Key Learning
This practical helped me understand how software instructions change a GPIO output and produce a visible hardware result.

## Next Step
Learn GPIO BSRR and implement LED control using atomic set/reset operations.
